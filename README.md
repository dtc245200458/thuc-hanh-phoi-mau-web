# Thực hành: Sử dụng màu sắc trong trang web

Dựa trên Pra.zip của CodeGym, giữ bố cục và nội dung gốc.

## Mở bài
- index.html: bản xanh theo hướng dẫn.
- purple.html: bản tím đơn tông cho bước 8.
- Mở trực tiếp các file HTML bằng trình duyệt.

| Thành phần | Bản xanh | Bản tím |
|---|---|---|
| Chủ đạo, ON SALE/PREVIEW | #00ADEE | #7C3AED |
| Nút | #00B2EF | #8B5CF6 |
| Nền trang | #00BFF2 | #A78BFA |
| Thẻ nội dung preview | #8DD7F7 | #DDD6FE |
| Footer và thông tin cuối trang | #C6E9FA | #EDE9FE |
| Chữ | #000000 | #000000 |

Bản tím dùng bảng màu tự chọn. Logo và ảnh sản phẩm gốc được giữ nguyên. Các nút, biểu mẫu vẫn là phần minh họa của mẫu gốc; bài chỉ yêu cầu phối màu.
